# 游戏测评 JSON 导入导出设计

## 目标

为游戏测评页面增加 JSON 备份与恢复功能。用户可以导出全部测评数据和排序，也可以在 Electron 或普通网页中从本地 JSON 文件导入。备份不包含封面 URL 或本地文件路径。

## 范围

导出内容包括：

- 所有 Steam 游戏的测评记录；
- 所有自定义游戏的名称和测评记录；
- 游戏显示顺序；
- 类型、体验、时长、评分、推荐度和封面模糊状态。

导出内容不包括：

- Steam 或自定义游戏的封面 URL；
- 本地图片路径；
- 当前搜索、筛选、分页和浮层状态。

## JSON 格式

备份使用带格式标识和版本号的对象：

```json
{
  "format": "steam-pc-game-reviews",
  "version": 1,
  "exportedAt": "2026-09-28T12:00:00.000Z",
  "reviews": {
    "123456": {
      "appName": "游戏名",
      "type": ["卡牌"],
      "experience": "测评内容",
      "duration": "42",
      "rating": 5,
      "recommendation": "S",
      "coverBlurred": false
    }
  },
  "customGames": [
    {
      "appId": "custom-...",
      "appName": "自定义游戏",
      "review": {
        "type": [],
        "experience": "",
        "duration": "10",
        "rating": 4,
        "recommendation": "A",
        "coverBlurred": false
      }
    }
  ],
  "order": ["123456", "custom-..."]
}
```

`format` 防止用户误选其他 JSON 文件。`version` 支持后续格式迁移。`exportedAt` 仅记录备份时间，不参与合并。

## 数据边界

`gameReviewStorage.ts` 负责：

- 定义备份数据类型；
- 从当前记录、自定义游戏和排序生成备份；
- 解析并校验未知 JSON 数据；
- 合并导入数据与本地数据；
- 持久化自定义游戏，使其在应用重启后仍存在。

`GameReview.vue` 负责：

- 在操作区提供“导入记录”和“导出记录”按钮；
- 导出前同步当前编辑内容；
- 使用 `Blob` 和临时下载链接保存 JSON；
- 使用隐藏的 `<input type="file" accept="application/json,.json">` 读取本地文件；
- 导入成功后更新响应式状态和提示信息。

浏览器标准 API 同时服务 Electron 渲染页和普通网页。该功能不新增 preload 方法或 IPC 处理器。

## 导出流程

1. 将当前编辑状态同步到待导出记录。
2. 收集所有 Steam 测评、自定义游戏和当前排序。
3. 删除所有封面字段和路径。
4. 生成带两个空格缩进的 UTF-8 JSON。
5. 创建 `Blob` 和临时对象 URL。
6. 触发下载，文件名为 `game-reviews-YYYY-MM-DD.json`。
7. 撤销对象 URL，并显示成功或失败提示。

## 导入与校验

导入器先完整解析和校验文件，再修改任何本地状态。它将验证：

- 根对象的 `format` 与 `version`；
- `reviews` 是对象；
- `customGames` 和 `order` 是数组；
- AppID 和自定义游戏 ID 是非空字符串；
- 每项测评字段的类型和允许范围。

测评字段沿用现有规范化规则：无效文本归为空字符串，无效类型项被过滤，评分限制为 0 至 5，模糊状态只接受布尔值。结构或版本不受支持时，整个导入失败，本地数据保持原样。

## 合并规则

导入以 AppID 为记录标识：

- 导入文件中的类型、体验、评分、推荐度、游戏名和模糊状态覆盖本地同 ID 字段；
- 时长比较有效数值后保留较大值；
- 一侧时长为空或无效时，保留另一侧的有效值；
- 本地独有和导入独有的记录都保留；
- 导入排序放在前面，本地独有 ID 按原顺序追加；
- 排序中的重复或不存在 ID 被移除。

自定义游戏也按 `appId` 合并。导入后统一设置 `coverUrl: ''`。导入的自定义游戏写入独立持久化数据，重启后仍会恢复；其测评内容与普通记录一起持久化。

## 状态更新

导入成功后按以下顺序更新页面：

1. 合并并写入 Steam 测评记录；
2. 合并并写入自定义游戏；
3. 重建当前草稿；
4. 应用合并后的排序；
5. 清除当前筛选并回到第一页；
6. 显示导入记录数量。

这样可避免响应式监听器在半完成状态下保存不完整数据。

## 错误处理

- 用户取消选择文件时不显示错误。
- 文件不是合法 JSON 时提示“无法读取 JSON 文件”。
- 格式标识或版本不支持时提示“不是受支持的游戏测评备份”。
- 校验失败时不修改任何本地数据。
- 下载失败时显示导出错误，但保留当前编辑内容。

## 验证范围

实现应覆盖以下行为：

- 导出不包含任何封面字段；
- 有效备份可往返解析；
- 无效格式不会改变本地状态；
- 冲突字段由导入值覆盖；
- 时长始终保留较大有效值；
- 自定义游戏可持久化恢复，且封面为空；
- 导入排序优先，本地独有记录追加且无重复。

按用户偏好，实现过程中不自动运行测试、类型检查、构建、应用或浏览器自动化；如需执行，先征求明确同意。
